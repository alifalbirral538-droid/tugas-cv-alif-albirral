# Portofolio Alif Albirral

Situs CV satu halaman untuk tugas Pemrograman Web Session #4. Dibangun dengan HTML dan CSS terpisah, tanpa dependensi eksternal.

## Isi proyek

- `index.html`: profil, pendidikan, pengalaman, keahlian, dan formulir kontak.
- `style.css`: tata letak responsif dan gaya visual.
- `assets/foto-alif.jpg`: foto Alif yang diambil dari CV yang disediakan.

## Menjalankan secara lokal

Buka `index.html` di browser. Semua path CSS dan gambar bersifat relatif agar berfungsi di alamat GitHub Pages berbentuk `/REPONAME/`.

## Formulir kontak

Formulir menggunakan `mailto:` karena GitHub Pages adalah hosting statis. Setelah pengunjung menekan tombol, perangkatnya akan membuka aplikasi email. Pengunjung masih harus mengirim email dari aplikasi tersebut; situs ini tidak menyimpan pesan atau menjalankan server pengirim email.

## Publikasi GitHub Pages

Di repositori GitHub, buka **Settings > Pages**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/(root)`. URL menjadi `https://alifalbirral538-droid.github.io/tugas-cv-alif-albirral/` setelah deployment selesai.
